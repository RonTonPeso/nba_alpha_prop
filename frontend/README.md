# Frontend

Next.js dashboard for nba_alpha_prop. The page on `main` is a placeholder: title and one line that the app is under construction. TanStack Query is wired in `app/providers.tsx`. Recharts is not a dependency yet.

```bash
npm ci
npm run dev
```

Open http://localhost:3000.

The deployed placeholder is https://nba-alpha-prop.vercel.app.

`AGENTS.md` in this directory is the Next.js agent note. Read `node_modules/next/dist/docs/` before changing framework APIs. This app is on Next.js 16, which differs from older Next.js.
